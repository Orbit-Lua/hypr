# Hyprland Lua config

[![Check](https://img.shields.io/github/actions/workflow/status/Orbit-Lua/hypr/check.yml?branch=main&label=check&logo=githubactions&logoColor=white)](https://github.com/Orbit-Lua/hypr/actions/workflows/check.yml)
[![Hyprland](https://img.shields.io/badge/Hyprland-0.55%2B-58E1FF?logo=hyprland&logoColor=black)](https://hypr.land/)

Hyprland 0.55+ configuration in Lua for one Arch Linux workstation, with Vicinae menus, Noctalia theming, profile presets and a small helper CLI. It is specific to this machine, not a starter template.

## Install

[Nacre](https://github.com/abnertu/nacre) pins this repository as its `hypr-config` input and deploys it read-only to `~/.config/hypr`. Nacre also owns every long-running session application; Hyprland autostart here only runs the rainbow border helper.

To adopt a new revision, run `nix flake update hypr-config` in the Nacre checkout, then `nix flake update nacre` in the machine flake. To edit a local checkout live instead, set `users.users.<name>.development.hyprlandPath` to its absolute path in the machine flake; see Nacre's `docs/desktop-session.md`.

Runtime commands: `lua`, `vicinae`, `noctalia`, `qs` (Quickshell overview), `yad`, `ghostty`, `thunar`, `grim`, `slurp`, `swappy`, `wl-copy`, `notify-send`, `pw-play` or `paplay`, and `xdg-user-dir`.

## Usage

Hyprland loads `hyprland.lua`. `SUPER + /` opens the cheat sheet and `SUPER + SHIFT + /` searches every bind with its description.

| Change | File |
| --- | --- |
| Apps, paths, search URL, touchpad device | `lua/hyprconf/context.lua` |
| Keybinds | `lua/hyprconf/binds.lua` |
| Cheat sheet | `lua/config/key-hints.toml` |
| Quick settings (`SUPER + SHIFT + E`) | `lua/config/quick-settings.toml` |
| Window and layer rules | `lua/hyprconf/rules.lua` |
| Appearance, input, gestures, layout | `lua/hyprconf/options.lua` |
| Rainbow border default and sounds | `lua/config/effects.toml` |
| Default animation and monitor profiles | `lua/user/*.lua` |
| Animation and monitor presets | `profiles/<category>/*.lua` |

`noctalia.lua` is generated by Noctalia.

### Helper CLI

```sh
lua ~/.config/hypr/lua/bin/hypr.lua <command>
```

Run it without a command to list them. `screenshot` saves under `$(xdg-user-dir PICTURES)/Screenshots` and copies to the clipboard; `portal-hyprland` restarts the desktop portals.

### Runtime state

The deployed configuration is read-only, so choices made at runtime live in `$XDG_STATE_HOME/hypr` (default `~/.local/state/hypr`):

- `profile-selector` copies the chosen preset to `profiles/<file>.lua` and records it in `profiles/selected/<category>`. Without a selection, `lua/user/` applies.
- `rainbow-menu` writes `effects/rainbow-border-mode`; without it, `effects.toml` sets the mode.
- The palette derived from `noctalia.lua` is cached in `effects/colors-cache.lua`.

Delete a file there to return to the default. `HYPR_CONFIG_DIR`, `HYPR_STATE_DIR` and `EFFECTS_DIR` override the locations.
