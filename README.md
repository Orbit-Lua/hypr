# Hyprland Lua config

[![Check](https://img.shields.io/github/actions/workflow/status/Orbit-Lua/hypr/check.yml?branch=main&label=check&logo=githubactions&logoColor=white)](https://github.com/Orbit-Lua/hypr/actions/workflows/check.yml)

[![Lua](https://img.shields.io/badge/Lua-2C2D72?logo=lua&logoColor=white)](https://www.lua.org/)

Hyprland 0.55+ configuration in Lua for one Arch Linux workstation, with Vicinae menus, Noctalia theming, profile presets and a small helper CLI. It is specific to this machine, not a starter template.

The [workstation Nix configuration](https://github.com/gin31259461/nix-config) deploys it to `~/.config/hypr` and owns every long-running session application. Hyprland autostart here only runs the rainbow border helper.

## Layout

```text
hyprland.lua               entry point
lua/hyprconf/              modules: env, monitors, autostart, options, gestures, animations, binds, rules
lua/hyprconf/commands/     helper CLI commands
lua/bin/hypr.lua           helper CLI and its command list
lua/config/*.toml          autostart, quick settings, cheat sheet rows, effects
lua/user/*.lua             default active profiles
profiles/<category>/       animation and monitor presets
noctalia.lua               theme generated by Noctalia
```

## Where to change things

| Change | File |
| --- | --- |
| Apps, paths, search URL, touchpad device | `lua/hyprconf/context.lua` |
| Keybinds | `lua/hyprconf/binds.lua` |
| Cheat sheet (`SUPER + /`) | `lua/config/key-hints.toml` |
| Quick settings (`SUPER + SHIFT + E`) | `lua/config/quick-settings.toml` |
| Window and layer rules | `lua/hyprconf/rules.lua` |
| Appearance, input, gestures, layout | `lua/hyprconf/options.lua` |
| Rainbow border default and sounds | `lua/config/effects.toml` |

`SUPER + SHIFT + /` searches every bind with its description.

## Runtime state

The deployed configuration is read-only, so choices made at runtime live in `$XDG_STATE_HOME/hypr` (default `~/.local/state/hypr`):

- `profile-selector` copies the chosen preset to `profiles/<file>.lua` and records it in `profiles/selected/<category>`. Without a selection, `lua/user/` applies.
- `rainbow-menu` writes `effects/rainbow-border-mode`; without it, `effects.toml` sets the mode.
- The palette derived from `noctalia.lua` is cached in `effects/colors-cache.lua`.

Delete a file there to return to the default. `HYPR_CONFIG_DIR`, `HYPR_STATE_DIR` and `EFFECTS_DIR` override the locations.

## Helper CLI

```sh
lua ~/.config/hypr/lua/bin/hypr.lua <command>
```

Commands are listed in `lua/bin/hypr.lua`. Ones with side effects outside this config:

- `screenshot` saves under the Pictures screenshots directory and copies to the clipboard.
- `portal-hyprland` restarts the desktop portals.

## Validation

```sh
make all   # stylua, luacheck, keymap snapshot, hyprland --verify-config
```

`make keymap` compares every bind (keys, description, dispatcher, flags) with `tests/keymap.snapshot`, so refactors cannot change the keymap silently. After an intended change, regenerate it with `lua tests/keymap.lua > tests/keymap.snapshot` and review the diff. `make test` parses this checkout with a throwaway home; it does not run menus, screenshots or session behavior.
