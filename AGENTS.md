# AGENTS Instructions

Personal Hyprland 0.55+ Lua configuration for one active workstation. Preserve
current behavior unless the user explicitly asks for a behavior change. Keep
changes specific to this setup; do not turn the repository into a generic
Hyprland template.

Read [README.md](README.md) for layout and runtime state.

## Rules

- Keep the keymap unchanged unless the user asks: `make keymap` must pass. When a requested change alters binds, regenerate `tests/keymap.snapshot` and show the diff.
- The deployed config is a read-only Nix store path. Runtime writes go under `ctx.state_dir` (`$XDG_STATE_HOME/hypr`), never `ctx.config_dir`.
- Long-running session applications belong to the workstation configuration, Nacre (`~/.config/nacre`); `lua/config/autostart.toml` only holds compositor-owned work.
- Structured data (autostart, menu rows, cheat sheet, effects) stays in `lua/config/*.toml`.
- `noctalia.lua` is generated by Noctalia: never edit it by hand.
- Prefer helpers in `lua/hyprconf/util/`, `lua/hyprconf/cli.lua` and `lua/hyprconf/commands/common.lua`; add abstractions only to remove real duplication.
- Run interactive or session-mutating helper commands only when the task needs them.

## Validation

Run `make all` before treating a change as ready. It formats, lints, checks the keymap snapshot and parses the config with a throwaway home. It does not cover menus, screenshots, portals or session behavior: smoke-test those by hand when touched.

## Code Style

- Lua files use 2-space indentation, Unix line endings, and UTF-8.
- `stylua` config is in `.stylua.toml`.
- `luacheck` config is in `.luacheckrc`; `hl` is an allowed global.
- Keep shell command construction consistent with the local `shell_quote`
  helpers.
- Prefer the existing `---@class`, `---@field`, `---@param`, and `---@return`
  annotations when adding typed Lua structures.
- Preserve the current small-module organization. Do not collapse the config
  into one large file.

## Git

Conventional Commits, no attribution trailers. Push only when the user asks.
